# Railsベクター検索デモ 用語集

**作成日**: 2026年5月6日
**更新日**: 2026年5月6日

本用語集はプロジェクト全体の用語統一の権威ソースである。要件定義書・機能設計書・調査報告書・ADR を含むすべての文書、および実装コードは、本用語集に従って用語を使用する。

## 凡例

| 項目 | 説明 |
|------|------|
| 用語 | 正式な用語名（プロジェクト内で統一して使用する名称） |
| 定義 | 用語の意味を簡潔かつ正確に記述 |
| 別名 | 許容される同義語（正式用語の使用を推奨） |
| 禁止表現 | 混乱を招くため使用を避ける表現 |
| 英語名 | 対応する英語表記（コード上の命名・URLパス等に使用） |
| コンテキスト | この用語が使用される境界づけられたコンテキスト。本デモでは「共通」「ベクター検索」「アプリ実装」「スコープ外」のいずれか |

## 技術

### ベクター検索の基礎概念

| 用語 | 定義 | 別名 | 禁止表現 | 英語名 | コンテキスト |
|------|------|------|----------|--------|-------------|
| ベクター検索 | クエリ文と対象データを高次元ベクトルに変換し、ベクトル間の類似度で検索する手法 | ベクトル検索, セマンティック検索 | 意味検索（曖昧で文脈依存のため、初出時のみ補足として可） | vector search | ベクター検索 |
| 埋め込みベクトル | テキスト等の情報を意味的な特徴を保持した固定長の数値ベクトルに変換した結果 | embedding（コード・図中のみ可） | 埋め込みデータ, 埋め込み（単独）, ベクトル（単独） | embedding | ベクター検索 |
| 埋め込みモデル | テキストを埋め込みベクトルに変換するモデル。本デモではローカル動作可能なものを採用する | embedding model | 埋め込み生成器（曖昧） | EmbeddingModel | ベクター検索 |
| 類似度 | 2つのベクトル間の近さを表す指標。コサイン類似度・内積・ユークリッド距離 等が用いられる。本デモで採用する具体指標はADRで決定する | 類似度スコア | 距離（厳密には距離と類似度は逆向きの指標のため、混用しない） | similarity | ベクター検索 |
| コサイン類似度 | 2つのベクトルのなす角度のコサインに基づく類似度指標。値域は-1〜1で、1に近いほど類似 | — | — | cosine similarity | ベクター検索 |
| 内積 | 2つのベクトルの要素ごとの積の総和に基づく類似度指標 | ドット積 | — | inner product / dot product | ベクター検索 |
| ユークリッド距離 | 2つのベクトル間の幾何的距離。値が小さいほど類似 | L2距離 | — | euclidean distance / L2 distance | ベクター検索 |
| top-K | 類似度の高い上位K件を返す検索方式 | 上位K件 | — | top-k | ベクター検索 |
| クエリ文 | 利用者が類似記事検索のために入力する短いキーワードまたは質問文 | — | クエリ（単独）, 検索クエリ, 検索ワード | query text | ベクター検索 |
| ベクターDB | 埋め込みベクトルを格納し、類似度に基づく検索を効率的に実行できるデータストア。pgvector 等のRDB拡張を含む。本デモで採用するものはADRで決定する | ベクターストア, ベクトルデータベース | ベクトルストア（表記揺れ） | vector database / vector store | ベクター検索 |
| ANNインデックス | Approximate Nearest Neighbor（近似最近傍）を高速化するためのベクトルインデックス。HNSW・IVFFlat 等のアルゴリズムが代表例 | 近似最近傍インデックス | — | ANN index | ベクター検索 |
| HNSW | ANNインデックスの代表アルゴリズム。階層的なグラフ構造で高速かつ高精度な近傍検索を実現する。pgvector が opclass `vector_*_ops` でサポート | Hierarchical Navigable Small World | — | HNSW | ベクター検索 |
| IVFFlat | ANNインデックスのアルゴリズム。ベクトル空間を多数のクラスタに分割して検索範囲を限定する。pgvector がサポート | Inverted File Flat | — | IVFFlat | ベクター検索 |
| L2正規化 | ベクトルを長さ（L2ノルム）で割って単位ベクトル（norm=1）に変換する処理。E5 系等の埋め込みモデルは出力を L2 正規化済みで返す | 単位ベクトル化 | — | L2 normalization | ベクター検索 |
| multilingual-e5 | 多言語対応の埋め込みモデルファミリ（intfloat 提供）。本デモでは `multilingual-e5-base`（768次元）を採用する。入力に `passage:` / `query:` プレフィックスを付与する規約がある | E5（同ファミリ） | — | multilingual-e5 | ベクター検索 |
